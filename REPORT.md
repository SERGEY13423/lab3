# ОТЧЁТ ПО ЛАБОРАТОРНОЙ РАБОТЕ № 3
## Линейные модели

## 1. Данные и подготовка

В лабораторной работе исследовались методы регрессии и бинарной классификации.

Для задачи регрессии использовался набор данных `Student_Performance.csv`. Целевая переменная — `Performance Index`, характеризующая индекс успеваемости студента. Признак `Extracurricular Activities`, содержащий значения `Yes` и `No`, преобразовывался в числовой формат: `Yes` — 1, `No` — 0.

Для задачи классификации использовался набор данных `german.csv`. Целевая переменная `Creditability` обозначает класс кредитоспособности: 1 — хороший заёмщик, 0 — плохой заёмщик.

В обоих экспериментах данные разделялись на обучающую и тестовую выборки в пропорции 80/20. Для разделения использовалось фиксированное значение `random_state=42`, позволяющее воспроизводить результаты. При классификации дополнительно применялась стратификация по целевому классу, чтобы сохранить соотношение классов в обучающей и тестовой выборках.

Для собственной модели классификации и моделей, чувствительных к масштабу признаков, применялась стандартизация. Параметры преобразования рассчитывались по обучающей выборке, а затем применялись к тестовой, чтобы избежать утечки информации из тестовых данных в обучение.

## 2. Гипотезы и эксперименты

### 2.1 Линейная регрессия

Цель эксперимента — оценить, насколько линейная модель способна прогнозировать индекс успеваемости по входным признакам. Для обучения собственной реализации использовался градиентный спуск с минимизацией среднеквадратичной ошибки (MSE).

Параметры эксперимента:
- скорость обучения (`learning_rate`) — 0,05;
- число эпох (`epochs`) — 800;
- доля тестовой выборки — 20%.

Качество оценивалось по MSE на тестовой выборке. В качестве базового уровня использовалось предсказание средним значением целевой переменной обучающей выборки.

### 2.2 Логистическая регрессия

Для бинарной классификации была реализована собственная логистическая регрессия. Модель использует сигмоидальную функцию для получения вероятности принадлежности к положительному классу и обучается методом градиентного спуска с использованием функции потерь бинарной кросс-энтропии.

Параметры эксперимента:
- скорость обучения (`learning_rate`) — 0,1;
- число эпох (`epochs`) — 1000;
- доля тестовой выборки — 20%;
- `random_state` — 42.

После обучения качество модели оценивалось на тестовой выборке с помощью ROC-AUC, Accuracy, Precision, Recall и F1-score.

### 2.3 Сравнение с моделями scikit-learn

Собственная логистическая регрессия сравнивалась с тремя моделями библиотеки `scikit-learn`:
- `LogisticRegression`;
- `DecisionTreeClassifier`;
- `KNeighborsClassifier` с числом соседей `k=5`.

Все модели оценивались на одной и той же тестовой выборке. Для логистической регрессии и KNN использовалась стандартизация признаков. Для дерева решений масштабирование не применялось, поскольку этот алгоритм не требует стандартизации входных признаков.

## 3. Результаты экспериментов

### 3.1 Регрессия

| Модель | MSE на тестовой выборке |
|---|---:|
| Базовый прогноз средним | 370,7730 |
| Собственная линейная регрессия | 4,0826 |

Среднеквадратичная ошибка собственной линейной регрессии значительно ниже ошибки базового прогноза. Это указывает на то, что модель извлекает полезные зависимости между входными признаками и индексом успеваемости.

### 3.2 Классификация

Результаты классификации на тестовой выборке приведены в таблице.

| Модель | ROC-AUC | Accuracy | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|---:|
| Собственная логистическая регрессия | 0,8081 | 0,7700 | 0,8013 | 0,8929 | 0,8446 |
| Logistic Regression (`scikit-learn`) | 0,8086 | 0,7700 | 0,8013 | 0,8929 | 0,8446 |
| Decision Tree (`scikit-learn`) | 0,6190 | 0,6800 | 0,7714 | 0,7714 | 0,7714 |
| KNN (`scikit-learn`, k=5) | 0,7412 | 0,7200 | 0,7692 | 0,8571 | 0,8108 |

ROC-AUC отражает способность модели разделять классы при разных порогах классификации. Accuracy показывает долю правильных предсказаний. Precision характеризует долю верных предсказаний положительного класса среди всех предсказаний этого класса, Recall — долю найденных положительных объектов среди всех фактически положительных. F1-score представляет собой гармоническое среднее Precision и Recall.

Собственная логистическая регрессия показала результаты, практически совпадающие с результатами `LogisticRegression` из `scikit-learn`. Значение ROC-AUC собственной модели составило 0,8081, а готовой реализации — 0,8086. Accuracy обеих моделей равна 0,7700, F1-score — 0,8446.

Из рассмотренных моделей худший результат по ROC-AUC показало дерево решений — 0,6190. KNN занял промежуточное положение с ROC-AUC 0,7412. В рамках проведённого эксперимента логистическая регрессия обеспечила наиболее высокие показатели среди сравниваемых классификаторов.

## 4. Выводы

В ходе лабораторной работы были реализованы и проверены модели линейной регрессии и логистической регрессии, а также проведено сравнение классификаторов с алгоритмами библиотеки `scikit-learn`.

1. В задаче регрессии собственная линейная модель получила MSE 4,0826, тогда как базовый прогноз средним значением дал MSE 370,7730. Следовательно, обученная модель значительно точнее базового подхода на использованной тестовой выборке.
2. В задаче классификации собственная логистическая регрессия показала ROC-AUC 0,8081 и F1-score 0,8446. Результаты близки к результатам готовой реализации `scikit-learn`, что подтверждает согласованность работы двух реализаций в данном эксперименте.
3. Среди сравниваемых классификаторов логистическая регрессия показала наибольший ROC-AUC и F1-score. KNN показал более низкие, но сопоставимые результаты, а дерево решений — наиболее низкое значение ROC-AUC.
4. Полученные результаты относятся к выбранным наборам данных, разделению на обучающую и тестовую выборки и заданным параметрам моделей. Для более общего сравнения потребовались бы дополнительные разбиения или кросс-валидация и подбор гиперпараметров.

Таким образом, цели лабораторной работы достигнуты: реализованы линейные модели, проведена оценка качества на тестовых данных и выполнено сравнение собственной реализации логистической регрессии с классическими алгоритмами машинного обучения.

## 5. Воспроизводимость

Код экспериментов разделён на два файла:
- `linear_models.py` — реализации моделей и функция сравнения с классификаторами `scikit-learn`;
- `run_experiments.py` — загрузка данных, разделение выборок, запуск экспериментов, расчёт метрик и сохранение результатов.

Для повторного запуска необходимо поместить файлы `Student_Performance.csv` и `german.csv` в рабочую папку проекта, установить необходимые зависимости (`numpy`, `pandas`, `scikit-learn`) и выполнить:

```bash
python run_experiments.py
```

Результаты экспериментов сохраняются в файл `experiment_results.json`. Фиксированное значение `random_state=42` используется для воспроизводимого разделения данных.
